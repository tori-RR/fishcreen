一个轻量的 Windows 托盘程序，用于在双屏环境中自动降低副屏亮度并显示渐变黑幕。

当前版本：`1.2.0`

## 运行环境

Windows x64、Microsoft Edge WebView2 Runtime。硬件调光需要显示器支持并启用 DDC/CI。

## 使用

1. 双击运行 `fishcreen.exe`。
2. 左键单击托盘图标打开设置，选择生效屏幕、运行模式和调光参数；关闭设置窗口后，程序继续在托盘运行。
3. 日常模式与观影模式使用固定预设，调整任意参数会自动切换到自定义模式。
4. 右键托盘图标可切换模式、开关“开机自动启动”、立即恢复副屏或退出。
